# История изменений

Формат ориентирован на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Проект находится на этапе развития и проверяется на синтетических DOCX/PDF.

## [0.2.0] — 2026-09-29

### Добавлено
- PDF → Markdown: текстовый слой, извлекаемые изображения, разделение по страницам, без OCR.
- Запуск в Windows через `start.bat` с автоматической проверкой и установкой отсутствующих зависимостей.
- Контекстное меню для `.docx` и `.pdf` с отдельной установкой и удалением, без фоновой службы.
- Выбор папки назначения и защита от перезаписи результатов.
- Windows Release ZIP, пошаговая установка, FAQ, диагностика проблем и автоматическая публикация релизов после успешных тестов.

### Изменено
- Локальные пути изображений DOCX не попадают в alt-текст Markdown; ссылки на ресурсы остаются относительными.
- PDF не дублирует обычные страницы в PNG. Копия создаётся только для исключительно векторных страниц без извлекаемого текста/изображений.
- Расширены тесты для Windows и повторного запуска без скачивания библиотек.

### Известные ограничения
- Нет OCR и гарантии точной передачи сложной структуры PDF (колонки, таблицы, некоторые векторные элементы).
- Настоящие пользовательские методички ещё не предоставлены для расширенного регрессионного тестирования.
