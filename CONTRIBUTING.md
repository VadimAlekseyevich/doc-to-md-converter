# Как помочь проекту

Спасибо за желание улучшить конвертер. Начните с [Issues](https://github.com/VadimAlekseyevich/doc-to-md-converter/issues): опишите ошибку или предложите новую функцию.

Для ошибок укажите формат и свойства документа, ожидаемый и фактический результат и очищенный фрагмент `conversion.log`. Не публикуйте персональные и конфиденциальные файлы. По возможности создайте небольшой искусственный документ, который воспроизводит проблему.

Перед Pull Request установите зависимости разработки и выполните тесты:

```bat
py -3 -m pip install -e ".[dev]"
py -3 -m pytest -q
python scripts/build_release.py
```

Изменения конвертера должны сопровождаться тестами, особенно для вложенных изображений, путей Windows и защиты от перезаписи. Не добавляйте `.venv`, `dist` и личные документы. Крупные архитектурные изменения желательно сначала обсудить в Issue.

В репозитории пока не опубликован отдельный файл лицензии: условия повторного использования сторонними проектами следует согласовать с правообладателем.
