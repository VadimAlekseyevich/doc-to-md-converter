# DOCX / PDF → Markdown

**Локальный конвертер документов для Windows:** превращает DOCX и PDF в Markdown для GitHub, сохраняя изображения отдельными файлами. Не требует постоянной работы в фоне и не отправляет документы в облако.

> **Важно:** ZIP содержит исходное Python-приложение и готовый файл запуска под Windows, а **не автономный EXE**. На первом запуске установщик проверит Python и библиотеки; для недостающих компонентов может потребоваться интернет.

## 🚀 Запуск за три шага

1. Скачайте ZIP по кнопке выше и **извлеките всю папку** на диск (например, в `C:\Programs\`). Не запускайте программу изнутри открытого ZIP.
2. Откройте извлечённую папку и дважды нажмите **[start.bat](start.bat)**. При необходимости он проверит и установит Python 3.11+ через `winget` и отсутствующие библиотеки. Если Windows запрашивает разрешение, сначала убедитесь, что архив скачан из этого репозитория.
3. В окне выберите `.docx` или `.pdf`, при необходимости укажите папку назначения и нажмите **«Конвертировать»**. Результат появится в отдельной папке рядом с документом либо в выбранном каталоге.

**Git устанавливать не нужно.** Если репозиторий уже клонирован, достаточно `git pull` и двойного клика по `start.bat`. Подробнее: **[пошаговая инструкция для Windows](docs/INSTALL_WINDOWS.md)**.

## ✨ Возможности

| | DOCX | PDF |
| --- | --- | --- |
| Текст | Абзацы, заголовки, списки, ссылки и таблицы | Доступный текстовый слой; порядок чтения приблизительный |
| Изображения | Копируются из DOCX побайтно | Извлекаются отдельно; JPEG по возможности без перекодирования |
| Сканированные страницы | Вложенные изображения сохраняются | Картинки сохраняются, текст внутри не распознаётся |
| Результат | `index.md`, `assets/`, `conversion.log` | Те же файлы и отдельные разделы по страницам |
| Перезапись | Предыдущие результаты сохраняются | Предыдущие результаты сохраняются |

**Без OCR.** Конвертер не подменяет картинки текстовым описанием. Только для PDF-страниц исключительно с векторной графикой и без извлекаемого текста/картинок сохраняется изображение всей страницы. Обычные страницы целиком не дублируются.

## 🖱️ Конвертация по правому клику

Дополнительная возможность: один раз запустите **[install-context-menu.bat](install-context-menu.bat)** двойным кликом. После этого на файлах `.docx` **и** `.pdf` будет доступно: правая кнопка → **«Показать дополнительные параметры»** (Windows 11) → **«Конвертировать DOCX/PDF в Markdown»**.

Конвертер запустится только на время обработки, покажет сообщение об итоге и завершится. Программы по умолчанию для DOCX/PDF не меняются; регистрация команды не требует прав администратора. Удаление пункта меню — [uninstall-context-menu.bat](uninstall-context-menu.bat). Если папка приложения перенесена, запустите установщик пункта меню повторно.

## 📁 Как выглядит результат

Для `lecture.pdf` создаётся новая папка:

```text
lecture.pdf
lecture_md/
├── index.md
├── assets/
│   ├── images/
│   │   ├── image1.jpeg
│   │   └── image2.png
│   └── pages/           # только для исключительно векторных PDF-страниц
│       └── page3.png
└── conversion.log
```

Ссылка в `index.md` выглядит так:

```markdown
![Схема](assets/images/image1.jpeg)
```

**Для просмотра на GitHub загружайте всю папку `lecture_md/` вместе с `assets/`.** Абсолютные локальные пути вида `C:\Users\...` не используются. Исходный файл остаётся нетронутым. Если папка результата уже существует, создастся `lecture_md_2/`, затем `lecture_md_3/` и т. д.

## 🧰 Командная строка (необязательно)

```bat
start.bat "C:\Docs\lecture.docx"
start.bat "C:\Docs\lecture.pdf" --output-parent "C:\Exports"
start.bat "C:\Docs\lecture.pdf" --output "C:\Exports\special-export"
```

`--output-parent` задаёт существующую папку, внутри которой создаётся новая папка результата; `--output` — точный путь к ещё не существующей папке. Без аргументов `start.bat` открывает GUI.

## ❓ Ограничения и ответы

- **PDF не равен DOCX:** колонки, сложные таблицы, переносы и векторные элементы смешанных страниц могут передаваться неточно. Предупреждения записываются в `conversion.log`.
- **Скан PDF без текстового слоя не станет редактируемым текстом:** OCR намеренно отсутствует.
- **Документы обрабатываются локально.** Интернет используется для установки недостающих Python-компонентов.
- **Папка результата автономна:** `index.md` и `assets/` храните вместе.
- На сложных реальных DOCX/PDF совместимость ещё предстоит проверить; тесты покрывают синтетические документы и запуск на Windows.

Ответы на частые вопросы — [FAQ](docs/FAQ.md). Проблемы с Python, `pypi.org` или меню Windows — [руководство по устранению неполадок](docs/TROUBLESHOOTING.md).
