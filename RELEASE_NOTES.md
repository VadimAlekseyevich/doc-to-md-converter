# DOCX / PDF → Markdown v0.2.0 — Windows

Удобная для распространения Windows-версия: распаковать ZIP и запустить **`start.bat` двойным кликом**. Git не требуется.

### Как установить
1. Скачайте приложенный файл **`doc-to-md-converter-v0.2.0-windows.zip`** в разделе Assets.
2. Извлеките всю папку на диск — не запускайте файлы изнутри открытого ZIP.
3. Запустите `start.bat`. При первом запуске может потребоваться интернет для Python 3.11+ и недостающих библиотек.
4. Выберите DOCX или PDF и нажмите «Конвертировать».

### В релизе
- DOCX: текст и вложенные оригинальные изображения.
- PDF: доступный текстовый слой, изображения и разделы по страницам, без OCR.
- Нет лишних полностраничных PNG; исключение — страницы исключительно с векторной графикой без извлекаемого содержимого.
- Относительные ссылки для GitHub, автономная выходная папка и защита от перезаписи.
- Опциональная команда контекстного меню Windows для DOCX/PDF через `install-context-menu.bat`; удаление через `uninstall-context-menu.bat`. Фоновая служба не нужна.
- README, инструкции по установке, FAQ и устранению неполадок.

**Это ZIP исходного Python-приложения с Windows-скриптом запуска, не автономный EXE.** Windows 10/11, Python 3.11+. Для сложных реальных документов нужна дополнительная проверка; OCR и точное восстановление таблиц/вёрстки PDF не заявлены.
