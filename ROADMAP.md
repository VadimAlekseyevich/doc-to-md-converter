# Roadmap: DOCX → Markdown

## Цель

Конвертировать методички из `.docx` в читаемый на GitHub Markdown **вместе со всеми изображениями**, чтобы результат можно было хранить в Git как обычные текстовые файлы и ресурсы. OCR не нужен: текст берём из структуры DOCX, изображения сохраняем как файлы, не распознавая текст внутри них и не перекодируя их без необходимости.

## Стек

- **Python 3.11+**
- **python-docx + lxml + zipfile** — разбор структуры DOCX, связей и вложенных медиафайлов.
- **Tkinter** — минимальный desktop GUI без отдельного фронтенда.
- **pytest** — проверка конвертации на тестовых документах.

## Структура результата (MVP)

Рядом с `method.docx` создаётся папка `method_md/`:

```text
method.docx
method_md/
├── index.md
├── assets/
│   └── images/
│       ├── image1.png
│       └── image2.jpeg
└── conversion.log
```

`index.md` ссылается на ресурсы **относительными путями**; всю папку `method_md/` можно загрузить в Git без исходного DOCX. В первой версии — один Markdown-файл на документ; разбиение на несколько файлов по главам можно добавить позже.

## Критерии готовности MVP

- Текст DOCX находится в Markdown, а изображения представлены **самими файлами**, без OCR и без подмены текстовым описанием.
- Все извлекаемые изображения сохранены, ссылки на них открываются в GitHub; ничего неподдерживаемого не теряется без предупреждения.
- Результат создаётся рядом с исходником, GUI показывает итог и ошибки конвертации.
