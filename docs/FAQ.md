# Частые вопросы

[← На главную](../README.md)

**Нужен ли Git для запуска?** Нет. Скачайте ZIP из [Releases](https://github.com/VadimAlekseyevich/doc-to-md-converter/releases/latest), распакуйте и запустите `start.bat`.

**Это EXE?** Нет. Это Python-приложение с Windows-скриптом автоматической настройки. Для первого запуска может потребоваться интернет.

**Что происходит с оригиналом?** DOCX/PDF не изменяется. Конвертер создаёт отдельную папку результата, существующие папки не перезаписываются.

**Распознаёт ли сканы PDF?** Нет: OCR не используется. Сохраняются доступный текстовый слой и изображения.

**Почему нет PNG для каждой PDF-страницы?** Чтобы не дублировать уже извлечённые текст и рисунки и не увеличивать размер. PNG появляется только у исключительно векторной страницы без извлекаемых текста или картинок.

**Можно ли выбрать место сохранения?** Да, в GUI или через `--output-parent`. Из контекстного меню результат сохраняется рядом с исходным файлом.

**Нужно ли держать приложение в фоне для контекстного меню?** Нет. Конвертер стартует при выборе команды и завершается после обработки и сообщения об итоге.

**Загружаются ли документы в интернет?** Нет, обработка локальная. Сеть нужна лишь при установке отсутствующих Python-компонентов.

**Что загружать на GitHub после конвертации?** Всю выходную папку: `index.md` и `assets/`; по желанию `conversion.log` после проверки на приватные пути.

**Как обновляться?** Если использован Git — `git pull`. Если скачан ZIP — распакуйте новый релиз в отдельную папку и при необходимости заново установите пункт контекстного меню.
