# Установка на Windows

[← На главную](../README.md) · [Решение проблем](TROUBLESHOOTING.md)

## Самый простой способ — без Git и командной строки

1. Откройте [последний релиз](https://github.com/VadimAlekseyevich/doc-to-md-converter/releases/latest).
2. В разделе **Assets** скачайте **`doc-to-md-converter-v0.2.0-windows.zip`**. Это архив Python-приложения с файлом запуска, не готовый EXE.
3. Нажмите правой кнопкой по загруженному ZIP → «Извлечь всё…» и выберите постоянный каталог, например `C:\Programs\`. Не запускайте `start.bat` внутри ZIP.
4. Откройте папку `doc-to-md-converter-v0.2.0` и дважды нажмите **`start.bat`**.
5. Скрипт проверит Python 3.11+, подготовит `.venv`, установит недостающие библиотеки и откроет приложение. Для первого запуска может потребоваться интернет и подтверждение установки Python через `winget`.
6. Выберите DOCX или PDF, укажите папку назначения при необходимости и нажмите **«Конвертировать»**.

В дальнейшем достаточно запускать тот же `start.bat`. Подходящие библиотеки не скачиваются повторно.

> Windows может показать запрос на запуск скачанного BAT-файла. Сначала проверьте источник архива и содержимое файла; не отключайте системную защиту ради установки.

## Где результат?

При пустом поле назначения `method.pdf` превращается в новую папку `method_md/` рядом с файлом. В ней будут `index.md`, `assets/` и `conversion.log`. Предыдущие результаты не перезаписываются: повторные запуски создают `method_md_2/`, `method_md_3/` и так далее.

## Контекстное меню (по желанию)

Запустите `install-context-menu.bat` в извлечённой папке двойным кликом. В классическом меню Проводника появится команда для DOCX и PDF. Для удаления используйте `uninstall-context-menu.bat`.

Меню регистрируется только для текущего пользователя без прав администратора. Windows сохраняет путь к `start.bat` на момент установки; после переноса папки повторно запустите установщик меню.

## Если установка не удалась

Проверьте [TROUBLESHOOTING.md](TROUBLESHOOTING.md) для случаев с Python, PyPI, VPN/прокси и Tkinter. Уже созданную `.venv` обычно удалять не требуется.

## Если репозиторий уже клонирован

```bat
git clone https://github.com/VadimAlekseyevich/doc-to-md-converter.git
cd doc-to-md-converter
start.bat
```

Для обновления используйте `git pull`. Переустанавливать контекстное меню после обычного обновления не нужно.
