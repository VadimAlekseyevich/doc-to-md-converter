# Обработка документов и конфиденциальность

Конвертация выполняется локально на вашем компьютере. Исходные DOCX/PDF не отправляются в облако для обработки; OCR не используется. При первом запуске `start.bat` может скачать Python и недостающие библиотеки из настроенных источников (`winget`, PyPI/`PIP_INDEX_URL`).

Результат содержит Markdown, изображения и журнал `conversion.log`. В журнале могут встречаться имена и пути исходных файлов — проверьте его перед публикацией. Не создавайте публичных Issues с личными документами или неочищенными логами.

Исходные текст и изображения не анонимизируются автоматически. Если документ содержит конфиденциальные сведения, проверьте и очистите выходную папку до публикации.
