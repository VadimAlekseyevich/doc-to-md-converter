# Если приложение не запускается

[← На главную](../README.md) · [Пошаговая установка](INSTALL_WINDOWS.md)

## `pypi.org` не отвечает / `ReadTimeoutError`

Python найден, но установка недостающей библиотеки прерывается из-за сети. `start.bat` уже задаёт таймаут 60 секунд с повторными попытками. Проверьте интернет, корпоративный прокси/VPN или разрешённый индекс Python-пакетов. Существующую `.venv` удалять не нужно.

Для медленного соединения откройте CMD в папке приложения и введите:

```bat
set PIP_DEFAULT_TIMEOUT=120
set PIP_RETRIES=3
start.bat
```

Если организация предоставляет собственный пакетный индекс, используйте `PIP_INDEX_URL` по инструкции сетевого администратора.

## `Python 3.11+ is required` / `winget` не найден

Установите Python 3.11 или новее с [официального сайта](https://www.python.org/downloads/windows/), с компонентом Tcl/Tk для GUI. После установки откройте новую консоль или запустите `start.bat` повторно. Скрипт также проверяет `py -3` и типовые расположения Python.

## Не появляется окно / ошибка Tkinter

Запустите `start.bat` из CMD, чтобы увидеть ошибку. При отсутствии Tkinter переустановите Python с компонентом Tcl/Tk. BAT-файл не является отдельным EXE.

## Не открывается PDF / не установились `pypdfium2` или Pillow

Для PDF нужны `pypdfium2` и `Pillow`. Повторите `start.bat` при доступе к пакетам Python. DOCX может работать и без PDF-библиотек. Зашифрованные PDF без ключа и повреждённые файлы не поддерживаются.

## В PDF отсутствует извлекаемый текст

Вероятно, это скан без текстового слоя. OCR нет: картинки сохранятся, но текст внутри не будет распознан.

## Изображения не видны на GitHub

Загружайте **всю папку результата** с `index.md` и `assets/images/`. Перемещение одного Markdown-файла разрывает относительные ссылки. Векторные объекты на смешанных PDF-страницах могут не переноситься — проверьте `conversion.log`. Полные PNG обычных страниц специально не создаются.

## Пропал пункт меню Windows

Запустите `install-context-menu.bat` из фактической папки приложения и проверьте «Показать дополнительные параметры». Если папку перенесли, повторите регистрацию; для удаления запустите `uninstall-context-menu.bat`. Фоновый процесс не требуется.

## Как сообщить об ошибке

Создайте [Bug report](https://github.com/VadimAlekseyevich/doc-to-md-converter/issues/new/choose). Укажите Windows/Python, действия, ожидаемый и фактический результат. Удалите из логов и примеров имена пользователей, приватные документы, адреса и пароли.
